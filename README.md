# JS&JS Apoyo Logístico S.A.S.

Sitio web corporativo y plataforma digital para **JS&JS Apoyo Logístico**, empresa especializada en soluciones integrales y tercerización de procesos logísticos (cargue y descargue, montacargas, picking/packing, cuartos fríos, transporte y maquilas).

---

## 📁 Estructura del Proyecto

```
Mejora JSYJS/
├── jsyjs-html/                   # Versión Web Estática (HTML5, Vanilla CSS, JS)
│   ├── css/                      # Hojas de estilo y animaciones
│   ├── js/                       # Lógica de interacciones, modales y carruseles
│   ├── img/                      # Activos gráficos, logos e ilustraciones
│   ├── index.html                # Página principal con Asistente Virtual & Chatbot
│   ├── quienes-somos.html        # Historia, misión, visión y valores
│   ├── nuestros-clientes.html    # Casos de éxito y sectores atendidos
│   └── trabaja-con-nosotros.html # Ofertas y formulario de vinculación
│
├── jsyjs-web/                    # Versión Aplicación Web (Next.js, TypeScript, TailwindCSS)
│   ├── src/                      # Componentes, vistas y utilidades
│   └── public/                   # Recursos estáticos
│
├── DOSSIER_CORPORATIVO_JSYJS.md  # Información institucional y comercial
└── INSTRUCCIONES_BOTPRESS_JSYJS.md # Configuración del Asistente Virtual IA (Botpress)
```

---

## 🚀 Características Principales

- **Diseño Moderno & Responsivo:** Optimizado para móviles, tablets y pantallas de escritorio.
- **Asistente Virtual IA:** Integración en tiempo real con chatbot de Botpress e ilustración interactiva.
- **Carrusel Multimedia:** Reproductor de procesos logísticos con reproducción continua.
- **Optimización SEO:** Metadatos, accesibilidad y tiempos de carga optimizados.

---

## 🛠️ Tecnologías

- **Frontend:** HTML5, CSS3 (Variables, Flexbox, Grid), JavaScript ES6+ / Next.js + TypeScript
- **Iconografía:** Lucide Icons
- **IA / Chatbot:** Botpress WebChat
